# Multiplexeur 8 vers 1

Multiplexeur de largeur paramétrable `N` (32 bits par défaut). Le signal `A` sélectionne l’une des huit entrées à transmettre à la sortie `Y`.

<img width="462" height="703" alt="image" src="https://github.com/user-attachments/assets/72288c12-36cd-460e-9b67-dfe2e78db986" />

## Principe de fonctionnement

| Sélection `A` | Sortie `Y` |
|:-------------:|:----------:|
| 000 | `in0` |
| 001 | `in1` |
| 010 | `in2` |
| 011 | `in3` |
| 100 | `in4` |
| 101 | `in5` |
| 110 | `in6` |
| 111 | `in7` |
